# RULES

1. Code hoá thêm so với EXP-01: §4 nợ thêm, thu nợ, còn nợ; §5 tiền nhập; §8 đơn có dòng âm là trả hàng; quy đổi đơn vị qua catalog; sổ sửa xe thành `lines`.
2. Cố ý chưa làm: helper lô, kho, giá vốn, lãi, thu máy cũ, hiệu ứng tăng giá, tách topping; model tự viết từ `tables`.
3. Holdout: 30 câu chưa dùng phát triển. Prompt v5 không chép câu nào trong holdout.
