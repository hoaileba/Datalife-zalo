# RULES

1. Chỉ đổi `column_roles.py`: thêm header vào `HEADER_ROLES` (mỗi header có bằng chứng từ mô tả README của shop khác, hoặc ghi rõ là riêng một shop), luật ngữ cảnh cho header mơ hồ, so header có xét dấu.
2. Không đổi `shop.py`, `normalize.py`: nối đầu đơn vào chi tiết dùng `join_order_fields` có sẵn.
3. Chuẩn hoá lại cả 44 shop vào nháp, liệt kê mọi file khác trước khi áp.
4. Không đổi `concepts.py` ở lần này: lô hàng biz_124 để sau.
5. Mốc oracle: EXP-20261106-03 (train 2324, public 570). Câu từ đúng thành sai phải giải thích.
